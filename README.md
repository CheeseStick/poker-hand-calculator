# Poker Hand Calculator (Web)

[Learn Poker](https://github.com/) iOS 앱의 **게임 플레이 계산기**를 그대로 옮긴 정적 웹앱입니다.
실제 테이블에서 폰 브라우저로 바로 쓰는 용도로 만들었습니다.

- 내 카드 2장 → 보드가 깔릴 때마다 한 장씩 선택
- **실시간 현재 최고 핸드** (2장이면 하이 카드/원 페어부터, 5장부터 완전 판정 + 핵심 카드 하이라이트)
- **예상 승률** (몬테카를로 500회, 상대 1~4명 선택)
- 무늬 탭 → 랭크 선택 UX, 선택 카드 탭으로 제거
- 새로고침해도 상태 유지(localStorage), 한/영 전환, 오프라인 동작(정적 파일뿐)

프레임워크·빌드 스텝 없음: `index.html` + `style.css` + `poker.js`(도메인 로직) + `app.js`(UI).

## 로컬 실행

```bash
open index.html          # 그냥 브라우저로 열어도 동작합니다
```

## 구조

| 파일 | 내용 |
|---|---|
| `poker.js` | Swift 도메인 로직 포팅: 5장 평가기(휠 스트레이트 포함), 7장 중 최적 조합, 부분 핸드(2~4장), 핵심 카드, 몬테카를로 승률 |
| `app.js` | 상태 관리 + 렌더링 + localStorage 영속화, 한/영 문자열 |
| `style.css` | 앱과 동일한 진초록 펠트 테마, CSS로 그린 카드 |
